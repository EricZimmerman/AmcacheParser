# DFIR Artifact Museum samples

From https://github.com/AndrewRathbun/DFIRArtifactMuseum (MIT license), `Windows/Amcache`:

- `Win10/APTSimulatorVM/Amcache.hve.gz` with `.LOG1.gz` and `.LOG2.gz`: a dirty Windows 10 hive (new format) and its transaction logs
- `Win2012R2/StolenSzechuan/Amcache.hve.gz` with `.LOG1.gz` and `.LOG2.gz`: a Windows Server 2012 R2 hive (old format)

They are gzipped; the tests decompress them.
